
# Siemens NX Sample Models

This repository is a **collection of Siemens NX Student Edition models** that I create and share for practice and learning.  
It includes various part files (`.prt`), drawings (`_dwg1.prt`), and assemblies.

---

##  Contents
- Part files (`*.prt`)
- Drawing files (`*_dwg1.prt`)
- Assembly files (`*_assembly*.prt`)

## Current models

Drill press table lock, in `NX_Models/`:

- `table.prt`
- `table_lock_lever.prt`
- `table_lock_lever_pin.prt`
- `table_lock_screw.prt`
- `column_support_dwg1.prt` (drawing)
- `Drill Press Table Lock_dwg1.prt` (drawing)

More files are in `NX_Models/CADFiles` and `DrillPress/Samples`.

As I continue designing in Siemens NX, I will keep adding more models here.

---

##  How to Use
1. Clone or download this repository:
   ```bash
   git clone https://github.com/AbhishekDubasi09/Siemens_NX_part_samples.git
   ```
2. Open the `.prt` files in **Siemens NX** (Student Edition or higher).
